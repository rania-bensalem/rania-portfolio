# Portfolio – Rania Ben Salem

Portfolio trilingue (FR / EN / DE) en HTML, CSS et JavaScript pur. Aucune dépendance, aucun build.

## Structure
- `index.html` : structure de la page
- `css/style.css` : styles et animations
- `js/i18n.js` : tous les textes en FR, EN et DE (à modifier ici)
- `js/main.js` : changement de langue, texte animé, apparition au scroll, formulaire

## Tester en local
Ouvrir `index.html` dans le navigateur.

## Déployer sur GitHub Pages
1. Créer un dépôt public `raniabensalem_portfolio`
2. Envoyer tous les fichiers à la racine
3. Settings > Pages > Deploy from a branch > main > / (root)
4. Site : https://TON-PSEUDO.github.io/raniabensalem_portfolio/

## Avec git
```
git init
git add .
git commit -m "Portfolio"
git branch -M main
git remote add origin https://github.com/TON-PSEUDO/raniabensalem_portfolio.git
```
